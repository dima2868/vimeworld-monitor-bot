# 🤖 Telegram-бот мониторинга онлайна VimeWorld (Лололошка & Фиксплей)

Telegram-бот для отслеживания онлайна игрового сервера VimeWorld. Бот автоматически отправляет уведомления в Telegram, как только **Лололошка** (`MrLalalashkaXXL`) или **Фиксплей** (`F1xPlay_`) заходят в сеть.

---

## 📌 Функционал

1. **Команда `/start`**: Приветствие и удобная интерактивная клавиатура.
2. **Проверка статуса по кнопке**:
   - 🎬 **Лололошка** (`https://vimeworld.com/player/MrLalalashkaXXL`)
   - 🎮 **Фиксплей** (`https://vimeworld.com/player/F1xPlay_`)
   - 📊 **Общий статус** (все ютуберы + создатель бота)
3. **Авто-Мониторинг**:
   - Автоматическая фоновая проверка каждые 30 секунд.
   - Как только статус меняется с `Не в сети` ➔ `В сети`, бот мгновенно отправляет уведомление всем подписанным пользователям.
4. **Профиль Создателя**:
   - 👑 [dima_286812312](https://vimeworld.com/player/dima_286812312) с отображением его текущего онлайна в режиме реального времени.

## 🛠️ Локальный запуск (Local Development)

### 1. Клонирование / Подготовка файлов
Убедитесь, что у вас установлен Python 3.10+.

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Создайте файл `.env` на основе `.env.example`:
```env
BOT_TOKEN=ваш_токен_от_BotFather
```

### 4. Запуск бота
```bash
python main.py
```

## 🚀 Деплой на Railway (Railway.app)

Проект полностью подготовлен для деплоя на хостинг **Railway**:

1. Загрузите файлы репозитория на GitHub (или используйте Railway CLI).
2. Зайдите на [Railway.app](https://railway.app/) и нажмите **New Project** ➔ **Deploy from GitHub repo**.
3. Выберите ваш репозиторий с ботом.
4. Зайдите в настройки деплоя в раздел **Variables** и добавьте переменную:
   - `BOT_TOKEN`: `Ваш_Токен_Telegram_Бота`
5. Railway автоматически соберет и запустит вашего бота через `python main.py` или Dockerfile!
